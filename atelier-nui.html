Works 01

美容室サイト

atelier nui

完全予約制・セット面3席の小さな美容室を想定したサイトです。「髪に、静かな余白を。」というコピーに合わせ、余白とくすみカラーで落ち着いた雰囲気をつくりました。

HTML / CSS / JavaScript

ターゲットと目的

ターゲット：30〜40代の女性。髪質改善やカラーにこだわりがあり、落ち着いた空間で丁寧に施術を受けたい人。

目的：サロンの世界観を伝えつつ、WEB予約まで迷わずに進んでもらうこと。

工夫したポイント

  1. 写真を主役にした非対称レイアウト

    ファーストビューは左にコピー、右に大きな写真を配置。雑誌のような余白で、高級感と落ち着きを表現しました。

  2. どのページからも予約できる導線

    ヘッダーとフッターに予約ボタンを置き、スマホでは画面下部に固定。スタイリストページからは「指名して予約」に直接進めます。

  3. 選んだ内容がすぐわかる予約画面

    メニュー・スタイリスト・日時を選ぶと、右側の予約内容と料金（指名料込み）がその場で更新されます。
